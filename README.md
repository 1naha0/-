本库包含四个任务
1.颜色分割实验
2.多边形检测实验
3.Tag识别 
4.视频中的特殊物体框选

采用python编写

使用的库为：OpenCV，numpy
其中OpenCV主要用于图像的处理；numpy用于数据的处理与计算。

视频所使用的编译器为pycharm

任务一：颜色分割
运行步骤：
需要一个 Python 编辑器（如 PyCharm / VSCode），下载任务一代码并复制进入编辑器新建的 .py 文件；打开 “视觉” 文件夹，下载其中的 “任务一.png” 图片作为运行图片样本，将图片拖入编辑器项目中，使图片与代码文件在同一目录中，点击运行，即可实现颜色分割效果。

任务二：多边形检测与最小框选
运行步骤：
需要一个 Python 编辑器（如 PyCharm / VSCode），下载任务二代码并复制进入编辑器新建的 .py 文件；打开 “视觉” 文件夹，下载其中的 “任务二.png” 图片作为运行图片样本，将图片拖入编辑器项目中，使图片与代码文件在同一目录中，点击运行，即可实现多边形检测与最小框选效果。

任务三：物体位姿解算（solvePnP）
运行步骤：
需要一个 Python 编辑器（如 PyCharm / VSCode），下载任务三代码并复制进入编辑器新建的 .py 文件；确保电脑摄像头正常连接，将待识别的矩形物体置于摄像头前，点击运行，即可实时显示物体轮廓与 3D 坐标轴位姿解算效果，按 q 键可退出程序。

附加题：视频目标追踪
运行步骤：
需要一个 Python 编辑器（如 PyCharm / VSCode），下载附加题代码并复制进入编辑器新建的 .py 文件；打开 “视觉” 文件夹，下载其中的 “附加题.mp4” 视频作为运行样本，将视频拖入编辑器项目中，使视频与代码文件在同一目录中，点击运行，即可实现视频中的目标追踪效果，按 q 键可提前退出程序。

以下进行各项任务的简略思路展示：
任务一：读取图片--转HSV--设定颜色上下限--生成掩码--开/闭运算--掩码提取目标区域--显示结果
任务二：读取图片--转灰度图--高斯模糊去噪--边缘检测--轮廓查找--计算面积筛选合适轮廓--多边形拟合（筛选的一部分）--得到最小外接矩形--画出特定轮廓
任务三：打开摄像头--转灰度图--找目标轮廓--多边形拟合（取 4 个角点）--构造 3D 物体点、2D 图像点--解算旋转向量 rvec、平移向量 tvec--投影 3D 坐标轴到图像（画 XYZ 轴）--画轮廓、画坐标轴
附加题：读取视频-- 定义本子颜色范围--逐帧循环处理视频--颜色空间转换--生成掩码 --形态学去噪--查找轮廓--过滤轮廓--过滤轮廓--多边形拟合-- 画框--显示画面
